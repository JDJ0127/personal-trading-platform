# 1.0 Checklist

## 目标

接入低成本真实数据，运行模拟盘，验证策略收益可靠性和稳定性。不进行真实交易。

## 上线前必须通过

- [ ] `./scripts/check_all.sh` 通过
- [ ] `./scripts/run_sample.sh` 通过
- [ ] `./scripts/run_baostock_smoke.sh` 通过
- [ ] `docs/real_data_smoke_result.md` 状态为 `success`
- [ ] BaoStock 30 只核心股票同步成功
- [ ] 数据中心覆盖率、缺失日期、缺失股票检查通过
- [ ] `./scripts/run_paper_daily.sh` 通过
- [ ] `./scripts/run_paper_replay.sh` 至少回放 5 个交易日通过
- [ ] 前端 `http://localhost:5173/` 可打开
- [ ] 数据中心显示最新行情日期
- [ ] 股票池有候选结果
- [ ] 策略信号页面不白屏
- [ ] 风控中心显示市场状态
- [ ] 模拟交易显示订单计划、风控动作、订单、成交
- [ ] 持仓组合显示模拟账户持仓
- [ ] 报告日志显示最近一次 `paper-pipeline`

## 建议上线前演练

- [ ] 使用 `config/universe_core.csv` 跑 30-60 只股票
- [ ] 覆盖最近 6-12 个月数据
- [ ] 连续回放至少 5 个交易日
- [ ] 检查权益曲线是否连续
- [ ] 检查保护性卖出是否能生成
- [ ] 检查风控 `PauseBuy` 是否阻止新增买入
- [ ] 检查 `runLog.json` 是否记录成功/失败
- [ ] 按 `docs/cloudbase_deploy.md` 完成国内静态看板部署演练

## 非 1.0 范围

- 真实券商交易
- 实时逐笔行情
- 自动下单
- 多用户权限
- 在线后端服务和云端自动交易任务

## 1.0 交付口径

系统可在本地稳定运行每日模拟盘，前端静态看板可部署上线并查看数据、信号、风控、模拟订单、持仓和运行日志。策略仍处于观察验证阶段。
