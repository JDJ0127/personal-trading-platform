# 1.0 RC1 Release Notes

## Release Scope

Personal A-share quant trading platform 1.0 RC1 is a local, single-user research and paper-trading release.

This release supports:

- Real daily-bar data sync through BaoStock
- Local SQLite data storage
- Stock pool filtering
- Factor scoring and strategy signals
- Market risk state and position limits
- Paper account persistence
- Daily paper trading workflow
- Historical paper replay
- Frontend JSON dashboards
- Run logs and data coverage checks

## Explicit Non-Goals

- No real broker connection
- No real order execution
- No intraday streaming or tick-level realtime system
- No multi-user access control
- No public production SLA

## Standard Local Run

```bash
cp .env.example .env
./scripts/check_all.sh
./scripts/run_sample.sh
./scripts/start_frontend.sh
```

Open:

```text
http://localhost:5173/
```

## Paper Trading Run

```bash
./scripts/run_paper_daily.sh
```

## Historical Replay

```bash
REPLAY_START=2024-03-25 REPLAY_END=2024-03-29 ./scripts/run_paper_replay.sh
```

## Validation Status

The current codebase has passed:

- Backend unit tests
- Frontend production build
- CLI smoke checks
- Browser verification for data center and replay pages

Known limitation: large BaoStock sync batches can be affected by upstream network instability. Use `SMOKE_CODE_OFFSET` and `SMOKE_MAX_CODES` to split validation into smaller batches.
